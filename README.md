# Queue Foi?

Projeto educacional de Pensamento Computacional com Python. A proposta é ler chamados de suporte de TI, apresentar métricas e indicar qual chamado deve ser atendido primeiro.

O painel e a fila de atendimento estão planejados para o terminal. A regra de triagem, os integrantes e as instruções de execução serão documentados conforme a implementação avançar.
